# A股研究台 v1.0

正式版 **v1.0**（应用版本 `1.0.0`），发布于 **2026-10-30**。
完整更新内容见 [发布说明](CHANGELOG.md)。

一个面向个人研究的 Streamlit A 股工作台。基础分析不依赖大模型：输入股票代码后，
即可查看行情、技术结构、关键价位、多周期共振、基本面、策略回测和消息情报；AI
只作为可选的解释与检索增强层。

> 输出基于公开历史数据与规则推演，仅供学习研究，不构成投资建议。

## 当前能力

- 决策仪表盘：趋势结构、5/20/60/250 周期收益、20 周期年化波动、60 周期最大回撤、
  年度区间位置、ATR 与量比。
- 五组规则信号：均线、MACD、KDJ、RSI、BOLL 每组一票，显示有效覆盖和一致程度，
  不把“一致度”伪装成上涨概率。
- A 股交易约束：只使用已收盘 K 线，支持 T+1、主板/创业板/科创板/北交所涨跌停口径，
  回测信号在下一交易日开盘执行。
- 研究模块按需加载：综合概览、多周期、基本面、策略回测、AI 助手互不阻塞；短线扫描、
  个股情报和全球要闻使用独立入口。
- 数据降级：新浪与腾讯历史行情互为备选；估值、财务和新闻接口失败时不阻断技术分析。
- 证据化 AI 助手：全景研判、交易计划、风险审计和新闻催化四种任务；输出必须引用
  技术、财务、回测或新闻证据，并区分事实、推断与数据缺口。
- 提示词分层：稳定角色与规则放在 system，动态证据放在经过转义的
  `<research_context>` user 消息，当前任务保持在上下文末尾；结构化研判优先使用
  JSON mode，并在接口不兼容时自动降级。
- 新闻质量层：个股与全球新闻按来源权威性、时效、标题相关度和事件影响排序，合并
  近似转载为事件簇、剔除栏目/行情入口页；抓取与 AI 研判解耦，没有 Key 也能查看情报。
- 有界检索：全市场检索采用“宏观覆盖 + 板块宽搜”，单一站点超时会降级，不再拖住整页。
- 持续研究闭环：研究项目可关联核心标的、同行、供应链和观察标的；版本化假设明确绑定
  支持/反对/待确认证据，AI 结论自动保存问题、模型、证据覆盖率、三种情景、失效条件、
  生成时价格和有效期；研究任务持久保存阶段及每个子问题的完成状态，到期后自动计算
  实际/基准超额收益并支持人工覆写复盘。
- 统一事件时间轴：公告、新闻、财报线索与单日涨跌/量比异动聚合到同一时间轴并叠加 K 线；
  计算事件后 1/5/20/60 个交易日收益和分市场基准超额收益，严格使用事件发生后的数据。
- 证据关系图：连接公司、人物、产品、供应链、行业、事件、来源、指标、投资假设和 AI 结论；
  AI 抽取关系默认待核验，结论可反向追溯到事件与证据。
- 独立预警：支持价格、涨跌幅、量比、技术结构、财务指标、公告/新闻关键词、事件类型、
  假设失效线索和复核到期；站内通知幂等去重，可选带 Bearer Token 的 Webhook。
- 组合风险：手动或 CSV 维护持仓，计算市值、盈亏、权重、行业/单股集中度、60 日动量、
  历史波动率、规模/动量/波动风格代理和 120 日相关矩阵，并展示共同供应链和影响持仓的
  最新事件。
- A 股查询规划：自动展开代码、公司简称/全称、英文别名并路由到巨潮、交易所、权威媒体；
  AI 可调用公司专题检索，网页与公告 PDF 正文可进一步核验。
- 搜索可观测性：展示各引擎最近一次成功、空结果或错误状态，区分“没有新闻”和“渠道故障”。
- 报告导出：当前规则报告可直接下载为 Markdown。

## 启动

建议使用 Python 3.10 或更高版本：

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

打开页面后，可直接点击侧栏示例标的，或输入 6 位股票代码。技术分析、基本面与回测
不需要 API Key。只有 AI 研究助手、AI 精选和需要模型归纳的情报功能需要在侧栏折叠区
配置模型。

## AI 配置

配置优先级为 `ASTOCK_AI_KEY` 环境变量、本机 `.streamlit/secrets.toml`、页面手动输入。
本机保存为明文，只适合个人电脑，禁止提交到版本库。技能提示词位于 `skills/*.md`。
默认技能使用低强度推理；新闻分类和翻译关闭深度思考，避免简单任务浪费推理预算。
模型返回的推理字段默认不展示，研究结论应通过证据引用、反证和失效条件解释。

## 搜索增强

所有联网搜索入口共用有界的研究循环：**拆解问题 → 动态查询 → 读取原文 →
检查证据与冲突 → 按缺口补搜 → 带引用回答**。这借鉴了主流研究型 Agent 的
迭代方式，而非复刻任何厂商的内部实现。全球要闻、个股情报、补充题材、AI 对话的
联网研究，以及 `web_search` / `stock_research_search` 都使用 `search_workflow.py`。
公告、快讯、本地证据库仍作为发现线索和一手来源入口，不再替代正文核验。

模型规划查询，看到搜索结果后选择阅读目标；失败时按时效、权威性和查询方向兜底选取正文。
每轮评估后可以改写查询、选择未读来源或停止；默认最多 3 轮、8 次查询、6 次正文
读取、40 个候选来源，研究循环等待预算 180 秒（不含最终回答/新闻研判）。
并发请求有独立超时；超出等待预算的在途请求可能仍在后台结束。
界面展示实际查询、原文读取状态、来源日期、冲突与证据缺口，不展示隐藏思维链。

事实候选的引用必须指向实际来源，而且引文必须出现在成功读取的正文中。
多个域名只标记为“多来源”，不能自动证明稿件独立或事实无误；完整性和语义支持
仍由模型评估。未读正文、窗口外/未知日期的新闻、只有社交线索的消息不能让核验
完成检查通过。预算耗尽或读取失败会保留部分结果及缺口，不补写新闻。

Agent 规划与核验使用当前配置的 AI 模型，会消耗模型额度；关闭“自动 AI 研判”
只关闭后续影响分析，不关闭搜索中的规划和核验。没有模型配置时明确使用基础检索；
模型调用失败则降级，均不声称已完成 Agent 核验。

### 全球要闻：广泛收集 → 产业链深挖 → A股研究推荐

全球要闻默认使用“广泛收集”目标：在所选时间/行业及检索预算内保留报道、快讯、
讨论、传闻与只有摘要的页面，不把官方确认或正文核验作为收录、分析和推荐的门槛。
只清除重复链接和纯导航页，同标题但不同链接的报道/观点保留，取消社交数量及120条
展示裁切。板块和来源筛选仍可由用户主动选择；“全部”不表示穷尽互联网或获得付费全文。

新华社（news.cn，兼识别 xinhuanet.com）、彭博、路透有指定来源检索，模型可继续
检索 AP、FT、WSJ、CNBC、BBC、日经及国内财经媒体。前三家即使模型提前停止，也会
在预算允许时补跑；失败、空结果、未检索分别记录，不把一条国际新闻冒充所有媒体均可用。
默认全球检索预算为4轮、12次查询、8次阅读、96个来源、240秒，不含翻译和后续分析。

启用“搜完自动深挖产业链并推荐A股”（有模型时默认开启）后，先用全部消息生成产业
主线，再增量检索上中下游、替代、配套及候选公司的年报/产品/业务资料，最后精化
研究推荐。产业补搜另有2轮、6次查询、4次阅读、32个来源、120秒预算。实现位于
`pulse_recommendations.py`。通常展示3—5支不同A股及新闻主线、具体业务、传导逻辑、
下一催化与风险；没有合理联系时不凑数，不输出无实时依据的买入价或收益保证。

证券代码须符合沪深北A股格式，并用腾讯行情名称尽力校对；已发现的名称/代码错配及
港美股标识不进入推荐。名称接口不可用时明确标“待校对”。公司业务资料引用只保留实际
读取且引文匹配的来源；其余为业务映射推演。补搜/精化失败保留原新闻和首轮推演，
不将其冒充完成的产业研究。新闻说法与假设保持原始语气，不展开真假辩论，也不把
情景推演写成已确认订单。新增补搜和精化会增加模型调用成本，不自动交易。

联网检索使用 [Agent-Reach](https://github.com/Panniantong/Agent-Reach) 推荐的上游工具：
Exa MCP 全网语义搜索和 Jina Reader 网页正文读取，无需搜索 API Key。AI 的 `web_search`、
`stock_research_search` 以及新闻检索共享这一搜索路径；`read_page` 优先读取 Markdown
正文，失败后直连网页，公告 PDF 仍用 `pdftotext` 提取正文与页码。

安装搜索依赖（Python >= 3.10、Node.js >= 20.11，需含 npm）：

```bash
python3 scripts/setup_agent_reach.py
```

Windows 使用 `python scripts/setup_agent_reach.py`。工具安装在被 Git 忽略的 `.astock/`
目录，Agent-Reach 固定到官方仓库提交 `a19a171fa980a0785849596492e0af4db800c82f`
（1.5.0），mcporter 固定到兼容 Node 20 的 0.7.3；不安装 PyPI 同名包、不注册全局技能。
安装后重启应用，在侧栏 AI 研究助手中把“联网搜索”设为“开启（Agent 研究搜索）”。
不同模型协议使用同一研究循环；旧的 `native` 设置兼容映射到此流程，不再自动走
厂商隐藏的 `:online` 搜索。项目自动发现本地 mcporter；如已有独立安装，可通过
`ASTOCK_MCPORTER_PATH` 指定可执行文件的完整路径。Exa 使用项目的
`config/mcporter.json`，不会导入其他编辑器的 MCP 配置。

检索支持 day/week/month/any，新闻范围支持精确天数（包含半年）；背景/历史资料可以
不限时间，备用引擎使用不窄于目标窗口的内置范围，再由新闻层过滤。有日期的 Exa
结果按窗口过滤；没有日期的结果标记为时间未知，
仅作为待核验线索。结果继续经过实体/站点过滤、URL 去重和权威来源排序。服务超时、
结果过期或无相关结果时自动切换到原有搜索源，渠道健康会记录 `agent-reach-exa` 和
`agent-reach-jina` 的实际状态。侧栏“依赖已安装”仅表示本地工具存在，不代表远端可用。
Twitter/X 已增加可选只读后端；Reddit、小红书等登录态专用通道仍需另行配置。

#### 配置 Twitter / X

Agent-Reach 推荐的 `twitter-cli==0.8.5` 与现有工具隔离安装在 `.astock/agent-reach-venv`，
不安装全局技能。首次在其他机器安装可运行 `python3 scripts/setup_agent_reach.py --twitter`。
登录凭据不能通过聊天、命令参数、仓库文件或模型提示词提供：

1. 自己在浏览器登录 `x.com`，使用 Cookie-Editor 导出 **Header String**。
2. 在本地交互终端执行以下命令，在隐藏提示中粘贴并回车（输入时看不到字符是正常的）：

```bash
.astock/agent-reach-venv/bin/python scripts/agent_reach_twitter.py configure
```

凭据仅保存为 Agent-Reach 的 `twitter_auth_token` / `twitter_ct0`，Linux/macOS 配置文件
`~/.agent-reach/config.yaml` 权限为 `600`；它是本地明文会话凭据，并非加密保险库。
其他设置保留，不复制旧版 bird/xfetch 配置，不自动读取任何浏览器 Cookie。
建议使用专用账号，并遵守 X 的服务条款；可能遇到失效、限流或账号限制。

```bash
# 只检查本地安装和凭据是否存在，不验证登录，也不联网
.astock/agent-reach-venv/bin/python scripts/agent_reach_twitter.py status
# 实际只读搜索；正常返回推文才证明本次搜索可用，空结果不能证明认证成功
.astock/agent-reach-venv/bin/python scripts/agent_reach_twitter.py search "semiconductor" --max 5
```

Windows 将 Python 路径改为 `.astock/agent-reach-venv/Scripts/python.exe`。
本项目入口仅允许配置、状态、搜索和读推文，不提供发帖/点赞/转发。
股票工具中的 `site:x.com` / `site:twitter.com` 定向检索会调用此通道并合并 Exa 结果；
搜到的推文正文缓存在进程内，后续原文阅读优先复用。缺少凭据、限流或超时仍走原有网页搜索。
其他网站和普通全网查询不会强制转成 Twitter 搜索。每次最多 20 条，不自动无限翻页，
记录真实 `agent-reach-twitter` 渠道健康，凭据不会进入搜索报告或 AI 上下文。
如网络需要代理，在本地自行设置 `TWITTER_PROXY`（例如 `http://127.0.0.1:7890`；
地址应使用自己的实际配置），不要把代理密码发到聊天里。
独立运行上游 `twitter` 不会读取 Agent-Reach 保存的配置，也可能自动提取浏览器 Cookie；
请使用本项目上述只读入口。

本地证据先使用 SQLite FTS5/BM25 检索，再增量查询互联网；官方、媒体及普通网页正文会
由新闻刷新、监控进程或研究库按钮增量补全并重建全文索引。备用的 DuckDuckGo、Google
News RSS 和 Bing RSS 无需 Key。可在侧栏填写备用 Brave、Tavily 或 Google Programmable
Search 配置，也可设置环境变量。模型会在共享循环中评估本地候选及网络原文，
不依赖外部 Embedding 服务。

```bash
export ASTOCK_BRAVE_API_KEY="..."
export ASTOCK_TAVILY_API_KEY="..."
export ASTOCK_GOOGLE_CSE_KEY="..."
export ASTOCK_GOOGLE_CSE_CX="..."
```

备用正式 API 失败后仍会自动使用免费来源。个股公告优先走巨潮/交易所直连，
社交内容只作为线索，不会被升级成官方事实。个人研究数据默认位于 `.astock/research.db`；
可通过 `ASTOCK_DB_PATH` 改为其他本机路径。

## 独立预警进程

单次扫描或每五分钟持续扫描：

```bash
python3 monitor.py --once
python3 monitor.py --interval 300
```

价格和技术规则最短每 5 分钟检查，公告、新闻、财务和复核规则最短每 30 分钟检查。
Webhook 为可选项；失败会指数退避重试三次，任何外部失败都不会阻断站内记录：

```bash
export ASTOCK_WEBHOOK_URL="https://example.com/webhook"
export ASTOCK_WEBHOOK_TOKEN="..."
```

默认 DeepSeek 模型为官方名称 `deepseek-flash`；旧模型名仍保留在候选提示中，便于兼容
已有中转服务。数据库使用版本化增量迁移，升级不会清空自选、假设、快照或新闻证据。

## 口径说明

- 红涨绿跌遵循 A 股习惯。
- 年化波动按 242 个交易日估算；最大回撤按收盘价计算。
- 回测包含配置的单边手续费，但不自动代入所有券商佣金、印花税和滑点。
- 除权日与新股特殊交易规则仍可能造成个别历史涨跌停标记偏差。
